# Modify Game Brick Breaker

---

##  Deskripsi Proyek
Pryek ini merupakan modifikasi dan pengembangan tingkat lanjut dari game **Brick Breaker (Block Breaker)** menggunakan bahasa pemrograman **Python** dan library GUI **Pygame**. Game ini dirancang secara modular dengan menerapkan prinsip-prinsip dasar Pemrograman Berorientasi Objek (*Object-Oriented Programming - OOP*), seperti enkapsulasi (*encapsulation*), pewarisan (*inheritance*), pemisahan tanggung jawab kelas, serta abstraksi logika game.
